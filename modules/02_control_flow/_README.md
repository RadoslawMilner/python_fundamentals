## Module 02 — Control Flow

Teraz zaczniemy wykorzystywać warunki do sterowania przebiegiem programu.

Poznamy:
  - if
  - elif
  - else
  - nested conditions
  - and
  - or
  - not
  - truthy / falsy values
Szczególnie ostatni punkt jest ważny w Pythonie.

Przykładowo:
```python
items = []

if items:
    print("Items exist")
else:
    print("No items")
```

Python pozwala wykorzystywać wartości bezpośrednio w warunkach, bez konieczności jawnego porównywania ich z True, False czy None.
